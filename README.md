# 안녕하세요, 백엔드 개발 인턴을 준비하는 개발자입니다.

Java와 Spring Boot로 서비스를 만들며, 데이터가 정확하게 처리되고 장애 상황에서도 일관성을 유지하는 방법에 관심이 있습니다. 기능을 구현한 뒤에는 동시성, 트랜잭션 경계, 테스트와 운영 흐름까지 살펴보려고 합니다.

### 프로젝트

- **[FinRisk Radar](https://github.com/kwonwnsduf/finrisk-radar)** — 금융 데이터를 수집·분석해 위험 요인과 근거를 보여주는 플랫폼입니다. Spring Boot 기반 API와 이벤트 처리, 테스트 및 배포 구성을 다뤘습니다.
- **[Ticket Reservation Backend](https://github.com/kwonwnsduf/ticket-reservation-backend)** — 좌석 중복 예매, 임시 선점 만료, 결제 실패 시 상태 정합성을 고려한 예매 백엔드입니다.
- **[OntoFlow AI](https://github.com/kwonwnsduf/ontoflow)** — 여러 시스템을 연결하는 플랫폼으로, 인증·권한·워크스페이스 분리와 감사 기록을 구현했습니다.

새로운 기술을 빠르게 배우는 것만큼, 문제를 재현하고 근거를 남기며 해결하는 과정을 중요하게 생각합니다. 인턴으로서 팀의 코드와 운영 방식을 배우고, 맡은 기능을 끝까지 책임지고 완성하겠습니다.
